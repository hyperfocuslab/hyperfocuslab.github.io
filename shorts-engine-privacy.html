shorts-engine 개인정보 처리방침

시행일: 2026년 10월 17일

shorts-engine은 HyperfocusLab(대표 이예준)이 자체 YouTube 채널 “AI한테 시켜봄”에 직접 만든 영상을 올리기 위해 쓰는 내부 도구입니다. 외부 이용자에게 제공하는 서비스가 아니며, 이 방침은 도구가 Google 계정 권한을 어떻게 쓰는지 설명합니다.

1. 요청하는 권한

  • YouTube 동영상 업로드 권한(https://www.googleapis.com/auth/youtube.upload) 하나만 요청합니다.
  • 이 권한으로 채널 운영자 본인의 채널에 영상 파일과 제목·설명·태그를 업로드합니다. 업로드 상태는 항상 “비공개”이며, 공개 전환은 운영자가 YouTube Studio에서 직접 합니다.

2. 처리하는 정보

  • Google이 발급하는 인증 토큰(액세스 토큰, 갱신 토큰)
  • 업로드 결과로 받는 동영상 ID와 공개 상태

다른 사람의 Google 계정 정보, 채널 구독자·시청자 정보, 이메일, 연락처는 수집하지 않습니다.

3. 보관 위치와 기간

  • 인증 토큰은 운영자의 컴퓨터에만 저장되며, 운영자 본인만 읽을 수 있는 파일 권한으로 보관합니다. 외부 서버로 보내거나 백업하지 않습니다.
  • 동영상 ID는 업로드 기록 확인용으로 운영자의 작업 폴더에 남깁니다.
  • 권한을 해제하거나 도구 사용을 멈추면 토큰 파일을 삭제합니다.

4. 제3자 제공

Google에서 받은 정보는 YouTube 업로드 외 목적으로 쓰지 않으며, 제3자에게 판매·공유·이전하지 않습니다. 광고나 AI 모델 학습에도 사용하지 않습니다.

shorts-engine이 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요구사항을 따릅니다.

5. 권한 해제

Google 계정의 서드파티 액세스 관리 페이지에서 언제든 shorts-engine의 권한을 해제할 수 있습니다. 해제하면 저장된 토큰은 더 이상 쓸 수 없습니다.

English summary

shorts-engine is an internal tool HyperfocusLab uses to upload its own videos to its own YouTube channel. It requests only the youtube.upload scope and always uploads videos as private. OAuth tokens are stored only on the operator's computer with owner-only file permissions and are never sent to other servers. Data received from Google APIs is used only for uploading, is not sold or shared, and is not used for advertising or AI training. shorts-engine's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions. Contact: hyperfocuslab3813@gmail.com
