MacやWindows PCのherdr-core上で動くClaude Codeエージェントが止まったとき、iPhoneのロック画面の通知からそのまま答えられる無料アプリです。

必要なもの

  • herdr-coreの中でClaude Codeを動かしているMacまたはWindows PC
  • PCとiPhoneの両方にインストールしたTailscale
  • PCにインストールするSheltieサーバー

接続する

  1. MacのターミナルまたはWindowsのPowerShellでインストールコマンドを実行します。
  2. インストーラーが表示するQRコードをiPhoneのカメラで読み取ります。
  3. Sheltieが開いたら、通知を許可します。

インストールコマンド（Macのターミナル）:

curl -fsSL https://raw.githubusercontent.com/hyperfocuslab/sheltie/main/install.sh | sh

macOS、python3、herdr-core（hc）、Tailscaleが必要です。QRコードをもう一度表示するには python3 ~/.local/share/sheltie/sheltie.py pair を実行します。アンインストールするには、同じコマンドの末尾を | sh -s -- --uninstall にして実行します。

インストールコマンド（WindowsのPowerShell、管理者としてではなく実行）:

irm https://raw.githubusercontent.com/hyperfocuslab/sheltie/main/install.ps1 | iex

Windows、Python 3.9以上、herdr-core（hc）、Tailscaleが必要です。サーバーはサインイン時にタスクスケジューラで自動的に起動します。QRコードをもう一度表示するには python "$env:LOCALAPPDATA\sheltie\sheltie.py" pair、アンインストールするには $env:SHELTIE_UNINSTALL=1; irm https://raw.githubusercontent.com/hyperfocuslab/sheltie/main/install.ps1 | iex を実行します。ソース: github.com/hyperfocuslab/sheltie（MIT）

よくある質問

通知が届きません。

iPhoneの設定 → 通知 → Sheltieで通知がオンになっているか確認してください。次に、PCの電源が入っていて、Sheltieサーバーが動いているか確認してください。

外出先でも使えますか？

はい。PCとiPhoneが同じTailscaleネットワークにあれば、どこからでも使えます。

データはどこに送られますか？

会話、プロンプト、ターミナル画面は、Tailscale経由でPCとiPhoneの間だけでやり取りされます。私たちを経由するのは通知だけです。通知（ターミナル名と短い状態の1行）と端末のプッシュトークンは、Cloudflare上の中継サーバーを通ってそのままAppleに渡され、保存もログ記録もされません。アカウントも分析もありません。詳しくはプライバシーポリシーをご覧ください。
