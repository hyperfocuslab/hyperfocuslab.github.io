在 Mac 或 Windows PC 上執行的 Claude Code 或 Codex 代理停下來時，可以直接從 iPhone 鎖定畫面的通知回覆的免費 App。

需要準備

  • 執行 Claude Code 或 Codex 的 Mac 或 Windows PC。核准與回答問題可直接在原本的終端機使用；即時終端機畫面、傳送訊息、從手機開始新工作，需要在 herdr-core（hc）中執行。
  • 電腦與 iPhone 都安裝 Tailscale
  • 安裝在電腦上的 Sheltie 伺服器

連線

  1. 在 Mac 的「終端機」或 Windows 的 PowerShell 執行安裝指令。
  2. 用 iPhone 相機掃描安裝程式顯示的 QR 碼。
  3. Sheltie 開啟後，允許通知。

安裝指令（Mac 終端機）：

curl -fsSL https://raw.githubusercontent.com/hyperfocuslab/sheltie/main/install.sh | sh

需要 macOS、python3 與 Tailscale。要再次顯示 QR 碼，請執行 python3 ~/.local/share/sheltie/sheltie.py pair。要解除安裝，請把同一行指令的結尾改成 | sh -s -- --uninstall 再執行。

安裝指令（Windows PowerShell，不要以系統管理員身分執行）：

irm https://raw.githubusercontent.com/hyperfocuslab/sheltie/main/install.ps1 | iex

需要 Windows、Python 3.9 以上與 Tailscale。伺服器會在登入時由工作排程器自動啟動。要再次顯示 QR 碼，請執行 python "$env:LOCALAPPDATA\sheltie\sheltie.py" pair；要解除安裝，請執行 $env:SHELTIE_UNINSTALL=1; irm https://raw.githubusercontent.com/hyperfocuslab/sheltie/main/install.ps1 | iex。原始碼：github.com/hyperfocuslab/sheltie（MIT）

常見問題

收不到通知。

請到 iPhone 的「設定」→「通知」→「Sheltie」確認通知已開啟。接著確認電腦已開機，且 Sheltie 伺服器正在執行。

不在家也能用嗎？

可以。只要電腦與 iPhone 在同一個 Tailscale 網路上，在哪裡都能用。

我的資料會傳到哪裡？

對話、提示與終端機畫面只透過 Tailscale 在你的電腦與 iPhone 之間傳送。只有通知會經過我們：通知（終端機名稱與一行簡短狀態）和裝置的推播權杖，會經由我們在 Cloudflare 上的中繼直接交給 Apple，不會被儲存或寫入記錄。沒有帳號，也沒有分析工具。詳情請見隱私權政策。
