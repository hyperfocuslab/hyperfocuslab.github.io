施行日: 2026年11月26日 · 開発者: Hyperfocus Lab

このポリシーはiOSアプリとAndroidアプリの両方に適用されます。Androidアプリで扱いが異なる点は「Androidアプリ」の項にまとめ、それ以外の項はiOSアプリについての記述です。収集する情報とアプリ内から送るお問い合わせは、どちらにも当てはまります。

収集する情報

Cockatooはアプリ内のお問い合わせから自分で送った内容（下の「アプリ内から送るお問い合わせ」を参照）を除き、個人情報を収集しません。アカウントはなく、分析ツールや広告SDKも使用しません。開発者があなたの録音や会話を見ることはできません。

端末内だけで処理するもの

  • あなたの声（録音）は開発者や外部のサーバーには送信しません。
  • 文字起こしはAppleの端末内音声認識で行います。
  • 発音の判定は、アプリに組み込まれた発音モデルを使ってiPhone内で行います。
  • AIの返答を読み上げる音声と、端末の言語への翻訳も端末内で作成します。その言語の翻訳用言語パックが端末にない場合は、Apple Intelligenceの端末内モデルを使用します。

Apple Private Cloud Computeに送られるテキスト

AIが英語で返答し、あなたの文を添削するために、文字起こししたあなたの発言（テキスト）とその会話のそれまでの内容をApple Intelligenceに送信します。リクエストは端末内モデルまたはAppleのPrivate Cloud Computeで処理されます。

  • 送信するのはテキストだけです。録音ファイルは送信しません。
  • その日の出来事について話すために書いたメモも、同じ方法でテキストとしてのみ送信します。他人の名前や勤務先の情報など、送信したくない内容は書かないでください。
  • Appleは、Private Cloud Computeに送信されたデータをリクエストの処理にのみ使用し、保存しないと公表しています。開発者がこのテキストを受け取ったり見たりすることはできません。

保存するものと削除するタイミング

  • 会話、文字起こししたテキスト、添削された文、発音の判定結果、あなたの録音、英語レベルの設定は、端末内のアプリの保存領域にあります。 端末のバックアップ（iCloudバックアップ、パソコンへのバックアップ）をオンにしていると、ほかのアプリのデータと同じようにバックアップに含まれ、新しい端末に移すときに録音も一緒に移ります。
  • 以前の録音と聞き比べられるよう、録音は期限なく保管します。アプリが整理するのは、どの記録にも紐づいていない録音ファイルだけです。
  • 復習と発音のクセの画面で項目をスワイプして削除すると、その記録と録音が端末から削除されます。
  • アプリを削除すると、端末に保存された記録もすべて削除されます。

権限

  • マイク: 英語で話した内容を録音し、文字起こしと発音の確認に使います。録音するのはボタンを押している間だけです。
  • 音声認識: 話した内容を端末内でテキストに変換するために使います。

アプリ内から送るお問い合わせ

アプリ内からお問い合わせを送ると、次の内容が Hyperfocus Lab に届きます。

  • 送られるもの: お問い合わせの内容、入力した場合は返信用メールアドレス、アプリのバージョン、OSのバージョン、端末モデル、言語、アプリが作成した端末識別子（iOSではidentifierForVendor）。
  • 保存される場所: Google Apps Script のサーバーを経由して、Hyperfocus Lab が管理する Google スプレッドシートに保存され、support@hyperfocuslab.app へメールで転送されます。
  • 使い道: お問い合わせへの返信のみに使います。
  • 削除: support@hyperfocuslab.app にご連絡いただければ、送られたお問い合わせを削除します。

Androidアプリ

Androidアプリ（com.hyperfocuslab.cockatoo）は、会話AIも端末内で処理します。Apple Intelligence、Private Cloud Compute、iCloudバックアップに関する記述はiOSアプリのみが対象です。

  • 会話AI: Google Gemini Nanoを端末内（Android AICore）で動かします。会話のテキストと添削は端末の外に送信しません。Nanoに対応していない端末では会話と添削は使えず、リピート練習と発音判定のみ使えます。
  • 文字起こし・発音判定・読み上げ: 文字起こし（Whisperベース）、発音判定、AIの返答を読み上げるAndroid端末の音声は、すべて端末内で処理します。録音は端末にだけ保存され、開発者や外部サーバーには送信しません。
  • モデルのダウンロード: 文字起こしと発音のモデル（約600MB）は、アプリのインストール直後にGoogle Playがダウンロードします（Play Asset Delivery）。この過程で開発者に届く情報はありません。
  • Androidの自動バックアップ: Googleアカウントのクラウドバックアップには、会話の履歴（テキスト）と設定が含まれます。保存先はご自身のGoogleドライブで、Androidの設定からオフにできます。録音ファイルはクラウドバックアップに含まれず、新しい端末へ直接移行するときの端末間転送にのみ含まれます。
  • Google ML Kit: ML Kitは、APIの利用状況とパフォーマンスの指標（会話の内容ではありません）をGoogleに送信することがあります。詳しくはML Kit利用規約をご覧ください。広告・分析SDKは使用していません。
  • お問い合わせ: 「アプリ内から送るお問い合わせ」の内容は、Androidアプリにもそのまま当てはまります。端末識別子は、iOSのidentifierForVendorの代わりに、アプリを初めて開いたときに作られるランダムな値を送ります。
