A free app that lets you answer a stopped Claude Code agent from your iPhone Lock Screen. The agent runs on your Mac or Windows PC, on top of herdr-core.

What you need

  • A Mac or Windows PC running Claude Code inside herdr-core
  • Tailscale on both the computer and the iPhone
  • The Sheltie server, installed on the computer

Connect

  1. Run the install command in Terminal on your Mac or in PowerShell on Windows.
  2. Scan the QR code the installer shows with your iPhone camera.
  3. When Sheltie opens, allow notifications.

Install command (Mac Terminal):

curl -fsSL https://raw.githubusercontent.com/hyperfocuslab/sheltie/main/install.sh | sh

Requires macOS, python3, herdr-core (hc) and Tailscale. To show the QR code again, run python3 ~/.local/share/herdr-remote/herdr_remote.py pair. To uninstall, end the same command with | sh -s -- --uninstall.

Install command (Windows PowerShell, not as administrator):

irm https://raw.githubusercontent.com/hyperfocuslab/sheltie/main/install.ps1 | iex

Requires Windows, Python 3.9+, herdr-core (hc) and Tailscale. The server starts at sign-in through Task Scheduler. To show the QR code again, run python "$env:LOCALAPPDATA\herdr-remote\herdr_remote.py" pair. To uninstall, run $env:HERDR_REMOTE_UNINSTALL=1; irm https://raw.githubusercontent.com/hyperfocuslab/sheltie/main/install.ps1 | iex. Source: github.com/hyperfocuslab/sheltie (MIT).

Common questions

Notifications are not arriving.

Check that notifications are on in iPhone Settings → Notifications → Sheltie. Then check that your computer is on and the Sheltie server is running.

Does it work away from home?

Yes, anywhere, as long as the computer and the iPhone are on the same Tailscale network.

Where does my data go?

Conversations, prompts and terminal screens travel only between your computer and your iPhone, over Tailscale. Only notifications pass through us: the notification (terminal name and a short status line) and your device push token go through our relay on Cloudflare straight to Apple, and are not stored or logged. There is no account and no analytics. Details are in the Privacy Policy.
