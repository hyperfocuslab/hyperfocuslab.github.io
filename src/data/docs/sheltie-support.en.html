A free app that lets you answer a stopped Claude Code agent from your iPhone Lock Screen. The agent runs on your Mac, on top of herdr-core.

What you need

  • A Mac running Claude Code inside herdr-core
  • Tailscale on both the Mac and the iPhone
  • The Sheltie server, installed on the Mac

Connect

  1. Run the install command in a terminal on your Mac.
  2. Scan the QR code the installer shows with your iPhone camera.
  3. When Sheltie opens, allow notifications.

Install command (Mac Terminal):

curl -fsSL https://raw.githubusercontent.com/hyperfocuslab/sheltie/main/install.sh | sh

Requires macOS, python3, herdr-core (hc) and Tailscale. To show the QR code again, run python3 ~/.local/share/herdr-remote/herdr_remote.py pair. To uninstall, end the same command with | sh -s -- --uninstall. Source: github.com/hyperfocuslab/sheltie (MIT).

Common questions

Notifications are not arriving.

Check that notifications are on in iPhone Settings → Notifications → Sheltie. Then check that your Mac is on and the Sheltie server is running.

Does it work away from my Mac?

Yes, anywhere, as long as the Mac and the iPhone are on the same Tailscale network.
