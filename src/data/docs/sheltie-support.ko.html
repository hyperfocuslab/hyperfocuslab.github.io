맥의 herdr-core 위에서 돌아가는 Claude Code 에이전트가 멈추면, 아이폰 잠금화면 알림으로 바로 답하는 무료 앱입니다.

필요한 것

  • herdr-core 안에서 Claude Code를 돌리는 맥
  • 맥과 아이폰에 설치한 Tailscale
  • 맥에 설치하는 Sheltie 서버

연결 방법

  1. 맥 터미널에서 설치 명령을 실행합니다.
  2. 설치기가 보여 주는 QR을 아이폰 카메라로 찍습니다.
  3. Sheltie가 열리면 알림을 허용합니다.

설치 명령(맥 터미널):

curl -fsSL https://raw.githubusercontent.com/hyperfocuslab/sheltie/main/install.sh | sh

필요한 것: macOS, python3, herdr-core(hc), Tailscale. QR을 다시 보려면 python3 ~/.local/share/herdr-remote/herdr_remote.py pair, 지우려면 같은 명령 끝을 | sh -s -- --uninstall로 바꿉니다. 소스: github.com/hyperfocuslab/sheltie(MIT).

자주 묻는 것

알림이 안 와요.

아이폰 설정 → 알림 → Sheltie에서 알림이 켜져 있는지 확인하세요. 그다음 맥이 켜져 있고 Sheltie 서버가 돌고 있는지 봅니다.

맥 밖에서도 되나요?

맥과 아이폰이 같은 Tailscale 네트워크에 있으면 어디서나 됩니다.

내 데이터는 어디로 가나요?

대화, 질문, 터미널 화면은 Tailscale을 거쳐 내 맥과 아이폰 사이에서만 오갑니다. 저희 서버를 거치는 건 알림뿐입니다. 알림(터미널 이름과 짧은 상태 문구)과 기기 푸시 토큰은 Cloudflare에 있는 저희 중계를 지나 Apple로 바로 넘어가고, 저장하거나 로그에 남기지 않습니다. 계정이나 분석 도구는 없습니다. 자세한 내용은 개인정보 처리방침에 있습니다.
