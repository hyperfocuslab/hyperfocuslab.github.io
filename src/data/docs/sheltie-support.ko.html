맥의 herdr-core 위에서 돌아가는 Claude Code 에이전트가 멈추면, 아이폰 잠금화면 알림으로 바로 답하는 무료 앱입니다.

필요한 것

  • herdr-core 안에서 Claude Code를 돌리는 맥
  • 맥과 아이폰에 설치한 Tailscale
  • 맥에 설치하는 Sheltie 서버

연결 방법

  1. 맥 터미널에서 설치 명령을 실행합니다.
  2. 설치기가 보여 주는 QR을 아이폰 카메라로 찍습니다.
  3. Sheltie가 열리면 알림을 허용합니다.

설치 명령은 공개 저장소가 열리면 이 페이지에 올립니다.

자주 묻는 것

알림이 안 와요.

아이폰 설정 → 알림 → Sheltie에서 알림이 켜져 있는지 확인하세요. 그다음 맥이 켜져 있고 Sheltie 서버가 돌고 있는지 봅니다.

맥 밖에서도 되나요?
