맥이나 윈도우 PC에서 돌아가는 Claude Code나 Codex 에이전트가 멈추면, 아이폰 잠금화면 알림으로 바로 답하는 무료 앱입니다.

필요한 것

  • Claude Code나 Codex를 돌리는 맥이나 윈도우 PC. 평소 쓰는 터미널 그대로 승인·질문에 답할 수 있고, 실시간 터미널 화면·메시지·폰에서 새 작업은 herdr-core(hc)로 돌릴 때 됩니다.
  • 컴퓨터와 아이폰에 설치한 Tailscale
  • 컴퓨터에 설치하는 Sheltie 서버

연결 방법

  1. 맥 터미널이나 윈도우 PowerShell에서 설치 명령을 실행합니다.
  2. 설치기가 보여 주는 QR을 아이폰 카메라로 찍습니다.
  3. Sheltie가 열리면 알림을 허용합니다.

설치 명령(맥 터미널):

curl -fsSL https://raw.githubusercontent.com/hyperfocuslab/sheltie/main/install.sh | sh

필요한 것: macOS, python3, Tailscale. QR을 다시 보려면 python3 ~/.local/share/sheltie/sheltie.py pair, 지우려면 같은 명령 끝을 | sh -s -- --uninstall로 바꿉니다.

설치 명령(윈도우 PowerShell, 관리자 권한 아님):

irm https://raw.githubusercontent.com/hyperfocuslab/sheltie/main/install.ps1 | iex

필요한 것: Windows, Python 3.9 이상, Tailscale. 서버는 로그인할 때 작업 스케줄러로 자동 시작됩니다. QR을 다시 보려면 python "$env:LOCALAPPDATA\sheltie\sheltie.py" pair, 지우려면 $env:SHELTIE_UNINSTALL=1; irm https://raw.githubusercontent.com/hyperfocuslab/sheltie/main/install.ps1 | iex. 소스: github.com/hyperfocuslab/sheltie(MIT).

자주 묻는 것

알림이 안 와요.

아이폰 설정 → 알림 → Sheltie에서 알림이 켜져 있는지 확인하세요. 그다음 컴퓨터가 켜져 있고 Sheltie 서버가 돌고 있는지 봅니다.

집 밖에서도 되나요?

컴퓨터와 아이폰이 같은 Tailscale 네트워크에 있으면 어디서나 됩니다.

내 데이터는 어디로 가나요?

대화, 질문, 터미널 화면은 Tailscale을 거쳐 내 컴퓨터와 아이폰 사이에서만 오갑니다. 저희 서버를 거치는 건 알림뿐입니다. 알림(터미널 이름과 짧은 상태 문구)과 기기 푸시 토큰은 Cloudflare에 있는 저희 중계를 지나 Apple로 바로 넘어가고, 저장하거나 로그에 남기지 않습니다. 계정이나 분석 도구는 없습니다. 자세한 내용은 개인정보 처리방침에 있습니다.
