Sheltieは、Hyperfocus LabのiPhone・Androidアプリです。ご自身のコンピューター（MacまたはWindows PC）にインストールしたサーバーに接続し、そこで動いているコーディングエージェントを表示します。本ポリシーでは、アプリが扱うデータとその送信先について説明します。

スマートフォンに保存されるもの

  • コンピューターのサーバーのアドレスとアクセストークン。トークンはiOSではキーチェーンに、AndroidではAndroid Keystoreの鍵で暗号化して保存します。
  • アプリの設定。

会話、プロンプト、ターミナル画面は、表示している間だけコンピューターから読み込み、アプリには保存しません。

コンピューターに送られるもの

アプリでの操作（回答、メッセージ、新しい作業）はすべて、ご自身のTailscaleネットワークを通じて、ご自身のコンピューター上のサーバーに送られます。このサーバーはお客様が実行するソフトウェアであり、当社はサーバーにもコンピューター上のデータにもアクセスできません。

当社のプッシュ中継を通るもの

通知を送るには、AppleとGoogleが求める当社だけが持つ鍵が必要なため、通知は当社がCloudflare Workersで運用する小さな中継サーバーを通ります。

  • 端末のプッシュトークン：通知をスマートフォンに届けるために、Apple（iPhone）またはFirebase Cloud Messaging（Android）が発行するものです。
  • 通知の内容：ターミナルの名前と、「approve Write: index.html」や「done」のような短い状態の1行です。

中継サーバーは、コンピューターのサーバーから送られた端末のプッシュトークンと通知を受け取り、そのままApple Push Notification serviceまたはGoogleのFirebase Cloud Messagingに渡します。トークンも通知の文面も保存せず、ログにも記録しません。

Cloudflare（中継サーバーのホスティング）、AppleとGoogle（通知の配信）は、通知を届ける目的に限ってこれらのデータを処理します。

当社が行わないこと

  • アカウント登録やサインインはありません。
  • アプリに分析・広告・トラッキングのSDKは含まれていません。
  • データを第三者に販売・共有しません。

このウェブサイト

本サイト（hyperfocuslab.app）では、訪問統計のためにGoogleアナリティクスを使用しています。アプリとは別のものです。

カメラ

カメラは、コンピューターに表示されるペアリング用QRコードを読み取るときにだけ使います。画像は保存も送信もしません。

マイク

マイクは、音声で返信を入力するときにだけ使います。音声はスマートフォンの音声認識サービス（AppleまたはGoogle）が文字に変換し、アプリが音声そのものを保存・送信することはありません。

お子様について

Sheltieは開発者向けのツールであり、13歳未満のお子様を対象としていません。

データの削除

アプリの設定でサーバーのアドレスとトークンを消去するか、アプリを削除すると、スマートフォンに保存されたデータが消えます。Macでは、install.sh --uninstall でサーバーを停止し、~/.config/sheltie を削除すると、設定と登録済み端末の一覧が消えます。Windowsでは、インストールスクリプトでアンインストールしたうえで（サポートページを参照）、%USERPROFILE%\.config\sheltie を削除してください。

アプリからのお問い合わせ

アプリ内からお問い合わせを送信すると、次の情報がHyperfocus Labに届きます。

  • 送信される内容：お問い合わせ本文、入力された場合は返信用メールアドレス、アプリのバージョン、OSのバージョン、端末の機種、言語、アプリが端末ごとに作成する識別子（iOSではidentifierForVendor、Androidではアプリが生成するランダムなID）。
  • 送信先：Google Apps Scriptのサーバーを経由し、Hyperfocus Labが管理するGoogleスプレッドシートに保存され、support@hyperfocuslab.appにメールで転送されます。
  • 利用目的：お問い合わせへの回答にのみ使用します。
  • 削除：support@hyperfocuslab.appにメールでご連絡いただければ、お問い合わせを削除します。
